# Bilder til Bilder-modulen

Legg bildefiler i denne mappen, så vises de automatisk i `Bilder`-modulen
på dashbordet (slideshow, 5 sekunder per bilde).

- Støttede formater: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`
- Bildene vises i alfabetisk rekkefølge etter filnavn
- Nye bilder plukkes opp automatisk ved neste oppdatering (uten rebuild)
- Anbefalt: liggende bilder (16:9) for best visning
